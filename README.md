# IAM Labs

Hands-on Identity and Access Management labs in **Okta** and **Microsoft Entra ID**, built to learn what an IAM engineer does day to day: onboarding apps, setting up SSO and MFA, automating joiner-mover-leaver, enforcing Conditional Access, governing privileged access, and troubleshooting sign-in issues.

## Skills Covered

| Area | Labs |
|---|---|
| User Lifecycle (JML) | 01, 02, 06, 09 |
| App Integration & SSO (SAML / OIDC) | 03, 04, 12, 14 |
| MFA & Conditional Access | 05, 07 |
| RBAC / ABAC & Governance | 06, 08, 15 |
| Privileged Access | 10 |
| Automation (PowerShell, Graph, Okta API) | 11, 16 |
| Troubleshooting | 12–16 |
